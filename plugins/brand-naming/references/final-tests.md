# Final tests

Apply every one of these to each finalist. Record the result — a test you
did not run is not a pass.

## Phonetic test

Pronounce the name conceptually in each target language, then run:

**HEAR → WRITE.** Someone hears the name once. Can they spell it?
Record the most likely misspelling. If there are three plausible
spellings, the name has a real cost.

**WRITE → SAY.** Someone reads it cold. Can they pronounce it?
Watch for digraphs that behave differently across languages (`ch`, `lh`,
`nh`, `j`, `x`, `z`) and for silent letters.

**PHONE TEST.** Can you say *"go to NAME dot com"* on a call without
spelling it out?

## Memory test

Simulate the name with no visual context:

```
"Do you know NAME?"
"That product was built by NAME."
"Remember that company called NAME?"
```

It has to survive being spoken, once, by a stranger.

## The "Made by" test

```
Made by NAME.          Designed by NAME.       Built by NAME.
NAME Cloud             NAME Studio             NAME AI
NAME Systems           NAME Platform
We hired NAME.         [local-language equivalent]
```

If the name only sounds like a company when you append `Tech`, `Labs` or
`Software` — discard it. The name has to stand alone.

## Wrong-category test

Does it read primarily as one of these?

clothing · textile · pharmaceutical · bank · fintech · cryptocurrency ·
supplement · restaurant · cosmetic · industrial · law firm

Penalise heavily on a strong association. Pharmaceutical is the most common
failure mode for Latin-flavoured coinages, and textile for soft
vowel-final Romance words.

## Visual test

Write it out and judge:

```
NAME      name      NAME®      name.com
```

- Does it work as a minimalist wordmark?
- Does it reduce to an icon?
- Is it attractive inside an interface?
- Does it work on a building?
- Does it work in an app store listing?

Watch letter shapes — repeated ascenders, awkward descenders, and
ambiguous `rn`/`m` or `l`/`I` pairs cause real design problems.

## Extensibility test

Imagine 15 years out:

```
NAME Cloud   NAME OS      NAME AI    NAME Studio
NAME Pay     NAME Mobile  NAME Research
```

The name must not limit the company it will become.

## The three closing questions

Answer these honestly before delivering anything:

1. If this became a $10B global company, would the name still feel right?
2. Would you put it on a keynote slide beside the reference brands without
   explaining or apologising for it?
3. Can you find any objective reason the founder regrets this in five years?

**If the answer to (3) is yes, do not deliver the name.** Go back and
generate another round. The goal is not to finish quickly. The goal is the
right brand.
