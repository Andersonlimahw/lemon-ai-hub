# Scorecard — 100 points

Score every survivor of the 30-candidate stage. Minimum **85/100** to reach
the finalist round.

| Criterion | Points | What you are judging |
|---|---|---|
| Essence / strategic fit | 15 | Does it fit the positioning without describing it? |
| Distinctiveness | 15 | Would it stand out in the category? |
| Memorability | 15 | Survives one hearing, no visual context |
| Simplicity | 15 | Length, syllables, cognitive load |
| Sophistication | 10 | Premium perception before any explanation |
| Pronunciation PT / EN / ES | 10 | Natural in all three, no coaching needed |
| Spelling clarity | 5 | Hear it once, write it correctly |
| Extensibility | 5 | Still works across future product lines |
| Visual potential | 5 | Wordmark, icon, interface, signage |
| Searchability | 5 | Findable; not drowned by a common noun |

## Scoring discipline

**Score never overrides collision.** A 98/100 candidate with a material
conflict is eliminated. A collision is not a deduction — it is a gate.

Score independently before researching collisions, so availability does not
bias your judgment of the name itself. Record both numbers.

## Category-flexibility check

Score `Extensibility` against the actual 15-year surface, not today's
offering. For a technology company, walk through:

```
NAME Cloud    NAME OS      NAME AI       NAME Studio
NAME Pay      NAME Mobile  NAME Research NAME Systems
```

If any of these reads as absurd, the name is narrower than it looks.

## Recording format

Use a table so the comparison is reproducible:

| Name | Fit /15 | Dist /15 | Mem /15 | Simp /15 | Soph /10 | Pron /10 | Spell /5 | Ext /5 | Vis /5 | Search /5 | Total | Decision |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

The `Decision` column must state the outcome and, when eliminated, the
specific evidence that killed it — not "weaker than others".
