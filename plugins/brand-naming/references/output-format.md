# Output format

Show **results and evidence**, not the internal reasoning chain.

Open with:

```
NAMING SPRINT — RESULT
```

## 1. Top 10

| Name | Score | Collision risk | Domain Status | Trademark risk | Main advantage | Main risk |
|---|---|---|---|---|---|---|

Domain Status is the transactionally-verified value from
`references/domain-verification.md` (`AVAILABLE` / `REGISTERED-PARKED` /
`ACTIVE` / `FOR SALE` / `NOT VERIFIED`) — never a DNS pre-filter guess.
A row showing `NOT VERIFIED` or `REGISTERED` must not appear as a
recommended winner.

## 2. Top 5 — full analysis

For each: origin and meaning, why it advanced, collision evidence with
URLs, domain status per TLD, preliminary trademark risk, weakest point.

## 3. Top 3

```
🥉 third
🥈 second
🥇 first
```

State objectively why each landed where it did.

## 4. Winner

```
DEFINITIVE NAME
NAME
```

Then:

```
Score: XX/100
Pronunciation PT-BR:
Pronunciation EN:
Pronunciation ES:
Origin / meaning:
Why it won:
Why it reads as a premium company:
Collision research:
Domain research:
Preliminary trademark risk:
International trademark risk:
Greatest weakness:
Confidence: X/10
```

State the greatest weakness honestly. A report with no stated weakness has
not been stress-tested.

## 5. Brand application

```
Made by NAME.
NAME Studio
NAME Cloud
NAME AI
```

Plus three possible tagline territories.

## 6. Evidence

Real URLs for conflicting companies, trademark results, domains, and the
national office. Mark anything unverified as `NOT VERIFIED`.

Never invent URLs, search results or availability.

## When there is no winner

Do not manufacture one. Replace sections 3–5 with:

```
NAMING SPRINT — NO CONVERGENCE
```

Then report:

1. Volume generated and screened, by category
2. Each finalist that died, and the specific evidence that killed it
3. The binding constraint — usually domain policy or category saturation
4. Concrete options for relaxing it, with the tradeoff of each
5. What the next round will explore differently

This is a legitimate result. Delivering a weak name that the founder
abandons in six months is a worse outcome than reporting an honest
non-convergence and running another round.
